# پنل چندبات و چندفرستنده Telegram Chat Automation

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/pirdel2002/telegram-chat-alert-worker)

یک پنل فارسی و سازگار با موبایل برای مدیریت چند بات تلگرام با رابط تبی و سایدبار دسترسی سریع. برای هر بات می‌توان چند فرستنده و چند هشدار مستقل ساخت:

- انتخاب یک فرستنده ثبت‌شده یا همه فرستنده‌ها
- فیلتر «هر پیام» یا «شامل عبارت»
- پیام هشدار دلخواه
- فاصله جلوگیری از تکرار
- فعال یا غیرفعال بودن قانون

در حالت «شامل عبارت»، متن و کپشن بررسی می‌شوند و تطبیق به حروف بزرگ و کوچک حساس نیست. اگر چند قانون با یک پیام منطبق شوند، پیام هشدار هر قانون جداگانه ارسال می‌شود.

## نصب آسان با موبایل

روی دکمه Deploy to Cloudflare بالا بزنید، وارد حساب Cloudflare شوید و برای ADMIN_PASSWORD یک رمز قوی انتخاب کنید. Cloudflare فضای KV و Worker را از روی تنظیمات پروژه می‌سازد.

توکن بات‌ها و تنظیمات قوانین داخل GitHub قرار نمی‌گیرند؛ همه آن‌ها بعد از نصب در پنل خصوصی Worker ثبت می‌شوند و توکن‌ها پیش از ذخیره در KV با AES-GCM رمزنگاری می‌شوند.

## راه‌اندازی

1. آدرس workers.dev ساخته‌شده را باز کنید و با ADMIN_PASSWORD وارد شوید.
2. نام نمایشی و توکن اولین بات را وارد کنید.
3. در BotFather برای همان بات، Secretary Mode را فعال کنید.
4. بات را در Telegram → Settings → Chat Automation حساب مربوطه متصل کنید.
5. در تب فرستنده‌ها، نام و شناسه عددی افراد موردنظر را اضافه کنید.
6. در تب هشدارها، فرستنده، نوع فیلتر و متن هشدار را تعریف کنید.
7. گفت‌وگوی خصوصی بات را باز و یک بار /start ارسال کنید.
8. از پنل، پیام آزمایشی بفرستید.

هر بات وب‌هوک و Secret مستقل دارد و هشدارهایش را در گفت‌وگوی خصوصی مالک همان بات ارسال می‌کند. برای افزودن بات‌های بیشتر همین مراحل را تکرار کنید.

## ارتقا از نسخه قبلی

توکن، اتصال بات و قوانین نسخه‌های قبلی به‌صورت خودکار منتقل می‌شوند. قانون‌های عبارتی نسخه ۲ به‌صورت «همه فرستنده‌ها + شامل عبارت» وارد نسخه ۳ می‌شوند.

اگر Cloudflare نسخه جدید را با Traffic صفر درصد ساخت، در بخش Deployments جدیدترین نسخه را Promote و Traffic آن را روی ۱۰۰ درصد قرار دهید.

## امنیت و حریم خصوصی

- نشست مدیریت امضاشده و همه فرم‌های مدیریتی دارای CSRF Token هستند.
- ورود در مرورگرهای موبایل با Origin خالی یا null پشتیبانی می‌شود، اما درخواست‌های صریحاً cross-site رد می‌شوند.
- وب‌هوک هر بات با Secret اختصاصی تلگرام بررسی می‌شود.
- متن پیام‌های دریافتی ذخیره نمی‌شود.
- فقط شناسه و نام تنظیم‌شده فرستنده، زمان و نتیجه آخرین رویداد برای عیب‌یابی نگهداری می‌شود.
- رمز و توکن را در GitHub، پیام‌رسان یا اسکرین‌شات عمومی قرار ندهید.

## توسعه محلی

دستورهای اصلی:

    npm install
    npm test
    npm run dev

برای بررسی بدون انتشار:
