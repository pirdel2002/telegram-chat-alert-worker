# پنل هشدار Telegram Chat Automation روی Cloudflare Worker

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/pirdel2002/telegram-chat-alert-worker)

## نصب آسان با موبایل

روی دکمه **Deploy to Cloudflare** بالا بزنید، وارد حساب Cloudflare شوید و فقط یک رمز قوی برای `ADMIN_PASSWORD` انتخاب کنید. فضای KV و Worker از روی تنظیمات پروژه ساخته می‌شوند. پس از پایان نصب، آدرس Worker را باز کنید و توکن ربات، شناسه عددی فرستنده و متن هشدار را در پنل فارسی وارد کنید.

توکن ربات و شناسه تلگرام داخل GitHub قرار نمی‌گیرند و فقط پس از نصب در پنل خصوصی Worker وارد می‌شوند.

این Worker پیام‌های `business_message` حساب تلگرام را دریافت می‌کند. اگر شناسه عددی فرستنده با شناسه تنظیم‌شده برابر باشد، متن هشدار دلخواه را در گفت‌وگوی خصوصی همان ربات برای مالک حساب می‌فرستد.

## امکانات

- پنل فارسی و سازگار با موبایل
- ورود مدیر با رمز و نشست امضاشده
- رمزنگاری توکن ربات با AES-GCM پیش از ذخیره در KV
- ثبت خودکار شناسه مالک از رویداد رسمی `business_connection`
- بررسی امضای Secret وب‌هوک تلگرام
- تنظیم شناسه فرستنده، متن هشدار و فاصله جلوگیری از تکرار
- دکمه ارسال پیام آزمایشی و غیرفعال‌کردن وب‌هوک
- عدم ذخیره متن پیام‌های دریافتی

## نکته مهم

دو ربات جدا لازم نیست. همان رباتی که به Chat Automation متصل می‌شود، هشدار را در گفت‌وگوی خصوصی خودش برای شما می‌فرستد.

## نصب از داشبورد Cloudflare

### ۱. ساخت Worker

در داشبورد Cloudflare وارد **Workers & Pages** شوید و یک Worker جدید با نامی مثل `telegram-chat-alert` بسازید. کد نمونه را حذف و تمام محتوای فایل `src/index.js` را جایگزین کنید، سپس Deploy بزنید.

### ۲. ساخت فضای KV

یک KV Namespace با نامی مثل `telegram-chat-alert-config` بسازید. سپس در تنظیمات Worker از بخش **Bindings** یک اتصال KV اضافه کنید:

- Variable name: `CONFIG_STORE`
- KV namespace: همان Namespace ساخته‌شده

### ۳. افزودن Secret مدیریت

در تنظیمات Worker، بخش **Variables and Secrets**، مورد زیر را با نوع **Secret** اضافه کنید:

| نام | کاربرد | پیشنهاد مقدار |
|---|---|---|
| `ADMIN_PASSWORD` | رمز ورود پنل | یک رمز طولانی و منحصربه‌فرد |
Worker کلیدهای نشست و رمزنگاری را با دامنه‌های جداگانه از همین رمز مشتق می‌کند. رمز را بعداً تغییر ندهید؛ در صورت تغییر، توکن ذخیره‌شده دیگر قابل رمزگشایی نیست و باید دوباره وارد شود.

برای استقرارهای پیشرفته می‌توان `SESSION_SECRET` و `CONFIG_ENCRYPTION_KEY` را نیز به‌صورت Secret جداگانه تعریف کرد، اما برای نصب شخصی لازم نیست.

### ۴. بازکردن پنل

آدرس Worker را باز کنید؛ مثلاً:

```text
https://telegram-chat-alert.<account>.workers.dev
```

با مقدار `ADMIN_PASSWORD` وارد شوید و این فیلدها را پر کنید:

- توکن ربات BotFather
- شناسه عددی فرستنده هدف
- متن هشدار، مثلاً `سایت قطع شد`
- فاصله جلوگیری از تکرار؛ مقدار پیشنهادی ۳۰۰ ثانیه

با زدن «ذخیره و فعال‌سازی وب‌هوک»، Worker ابتدا توکن را با `getMe` بررسی و سپس وب‌هوک را خودکار ثبت می‌کند.

### ۵. تنظیم BotFather و تلگرام

در `@BotFather`:

1. وارد **My Bots** و تنظیمات ربات شوید.
2. **Secretary Mode** را فعال کنید.
3. اگر فرستنده هدف خودش یک ربات است، **Bot-to-Bot Communication Mode** را نیز فعال کنید.

سپس در تلگرام:

1. به **Settings → Chat Automation** بروید.
2. username همین ربات را وارد و متصل کنید.
3. گزینه **Only selected chats** را انتخاب کنید.
4. فقط چت فرستنده هدف را اضافه کنید.
5. به پنل Worker برگردید. وضعیت Chat Automation باید «متصل» شود.
6. یک بار گفت‌وگوی خود ربات را باز و `/start` کنید.
7. دکمه «ارسال پیام آزمایشی» را بزنید.

## نصب با Wrangler؛ اختیاری

اگر نصب از کامپیوتر را ترجیح می‌دهید:

```bash
npm install
npx wrangler kv namespace create telegram-chat-alert-config
```

شناسه خروجی را در `wrangler.jsonc` جایگزین شناسه صفر پیش‌فرض کنید، سپس:

```bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler deploy
```

## رفع اشکال

- **پنل می‌گوید CONFIG_STORE ناقص است:** اتصال KV با همین نام ساخته نشده است.
- **توکن نامعتبر است:** توکن را مستقیماً از BotFather کپی کنید و فاصله ابتدا/انتها را حذف کنید.
- **وضعیت Chat Automation منتظر اتصال می‌ماند:** Secretary Mode فعال نیست، ربات در Chat Automation وصل نشده، یا وب‌هوک قبل از اتصال ذخیره نشده است.
- **پیام آزمایشی ارسال نمی‌شود:** ابتدا Chat Automation را متصل و سپس در چت ربات `/start` کنید.
- **پیام هدف هشدار نمی‌دهد:** شناسه عددی را بررسی کنید و مطمئن شوید چت هدف در فهرست دسترسی ربات قرار دارد.
- **فرستنده هدف ربات است:** Bot-to-Bot Communication Mode را فعال و دوباره آزمایش کنید.

## امنیت

- Worker را فقط از طریق HTTPS پیش‌فرض Cloudflare استفاده کنید.
- توکن ربات را در کد یا `wrangler.jsonc` قرار ندهید.
- رمزهای Secret را برای کسی ارسال نکنید.
- دسترسی Chat Automation را روی **Only selected chats** نگه دارید.
- Worker فقط شناسه فرستنده و زمان آخرین رویداد را ثبت می‌کند و محتوای پیام دریافتی را ذخیره نمی‌کند.
